# Data Structures and Algorithms
This repository contains coursework, assignments, source code, reports, and related materials for the Data Structures and Algorithms course.

## Assignment 1
Assignment 1 covers the following topics:
- Data Structure Selection
- OOP Concepts
- Time Complexity
- Bubble Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- Linear Search
- Binary Search
- Java Implementations
- Performance Comparisons
